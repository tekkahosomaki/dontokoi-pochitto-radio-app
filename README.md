# dontokoi-pochitto-radio-app

ポチッとラジオ — ブラウザで動くネットラジオプレーヤー。HTMLファイル1つで動きます(インストール不要)。

広告なしの海外ネットラジオ SomaFM と Radio Paradise の8局を、ボタンをポチッと押すだけで聴けます。
