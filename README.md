# dontokoi-pochitto-radio-app

ポチッとラジオ — ブラウザで動くネットラジオプレーヤー。HTMLファイル1つで動きます(インストール不要)。

SomaFM・Radio Paradise・KEXP・FIP など海外ネットラジオの64局を、ボタンをポチッと押すだけで聴けます。

- 公開ページ: https://tekkahosomaki.github.io/dontokoi-pochitto-radio-app/apps/pochitto-radio.html (SomaFM の11局は公開ページでは聴けません。聴くときはファイルをダウンロードしてダブルクリックで開いてください)
- アプリ本体: [apps/pochitto-radio.html](apps/pochitto-radio.html)
- 仕様: [docs/design](docs/design)
- 技術的な判断の記録: [docs/adr](docs/adr)
