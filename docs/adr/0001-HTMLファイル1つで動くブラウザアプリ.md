# ADR-001: HTMLファイル1つで動くブラウザアプリにし、Claude のアーティファクトで公開する

- **ステータス**: 採用
- **背景**: 海外のネットラジオを、インストールなしで手軽に聴けるようにしたい。英単語アプリ・集中トマトも HTML 1ファイルで作っており、同じ作り方にそろえたい。公開先は Claude のアーティファクトを想定している。
- **決定**: CSS と JavaScript を HTML の中に直接書き、ファイル1つだけで動くアプリにする。外部のスクリプト・スタイルシート・フォントは読み込まず、ビルド作業も不要とする。アーティファクトで公開するほか、ダブルクリックで開いて(`file://`)も動くようにする。
- **検討した代替案**: GitHub Pages で公開する案(今回はアーティファクトでの公開を想定しているため見送り。HTML 1ファイルなので、あとから載せることもできる)。Windows 用 exe にする案(スマホで聴けないため不採用)。
- **結果・影響**: ブラウザさえあれば PC でもスマホでも聴ける。ほかのアプリと違い、放送を受信するのでインターネット接続は必要になる(画面そのものはオフラインでも表示できる)。アーティファクトのページから海外の放送局の音声を読み込めるかどうかは未確認で、実装後に実際に公開して確かめる。
