# ADR(Architecture Decision Record)— ポチッとラジオ

このフォルダは、「ポチッとラジオ」の開発中に実際に行った技術的な判断を、決定1件ごとに1ファイルで記録したものです。各ファイルは次の形式でまとめています。

- **ステータス**: 採用 / 見送り など
- **背景**: なぜ判断が必要だったか
- **決定**: 何を選んだか
- **検討した代替案**: 他にどんな選択肢があったか
- **結果・影響**: 採用したことで何が得られ、何を引き受けたか
