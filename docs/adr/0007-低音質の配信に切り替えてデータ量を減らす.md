# ADR-007: 「通常 / 低音質」を選べるようにし、低音質は各局の 64kbps 前後の配信に切り替える

- **ステータス**: 採用
- **背景**: スマホのモバイル回線で聴くとき、データ量を減らしたい。通常の音質は局によって 128〜256kbps で、1時間あたり約58〜115MB になる。アプリ側で音声を圧縮し直すことはできない([ADR-004](0004-audioタグで再生する.md) のとおり音声は加工しない)ので、放送局が用意している低い音質の配信を使うしかない。2026-10-03 に34局を1つずつ調べると、19局は低い音質の配信を別の URL で出していた。
- **決定**: 音質の近くに「通常 / 低音質(データ節約)」のラジオボタンを置く。局の一覧には局ごとに通常の音質(`kbps`)と、あれば低音質の配信(`low: { kbps, url }`)を書く。低音質は 64kbps を目安にし、64kbps がない局は今より低いもののうち一番近いものにする(FIP 本局と Radio Swiss は 96kbps の AAC)。低音質を選んでいて、その局に低音質がないときは、通常の音質で流し、表示部に「通常音質のみ」と出す。再生中に切り替えたら、選んだ音質でつなぎ直す(数秒途切れる)。選んだ音質はブラウザ(localStorage)に覚えさせる。
- **検討した代替案**: 低音質を 32kbps にする案(データ量は通常の4分の1ほどになるが音がこもるため、64kbps を選んだ)。低音質のない局は、低音質を選んでいるときボタンを押せなくする案(聴けない局が増えるので不採用。通常音質で流して知らせる)。3段階(通常 / 64kbps / 32kbps)にする案(32kbps の配信がある局が少なく、選択肢が増えるわりに役立たないため不採用)。
- **結果・影響**: 低音質がある局では、データ量がおよそ3分の1〜半分になる(例: Radio Paradise 192kbps → 64kbps で約86MB → 約29MB/時)。低音質の配信は AAC が多いが、今のブラウザ(iPhone を含む)はどれも再生できる。2026-10-03 に、SomaFM 以外の11本が公開ページの上で再生できることを確かめた(SomaFM の8本は Claude の内蔵ブラウザでは試せないため、URL から音声が返ってくることまで確認)。NTS・Rinse FM・Intergalactic FM・FIP のサブチャンネル・Techno の一部(Techno.FM・Traxx FM・Technolovers・FluxFM)は低音質がなく、低音質を選んでも通常の音質で流れる。
