# ADR-003: https の直ストリームを公開している局だけを使う

- **ステータス**: 採用
- **背景**: 自作のページから放送を流すには、音声データそのもののURL(直ストリーム)が公開されている必要がある。日本の radiko や NHK らじる★らじるは、自分のページに組み込んで流すことが基本的にできない。また、アーティファクトのような https のページからは、`http://` のストリームは混在コンテンツとしてブラウザに止められることがある。
- **決定**: 第1版は、広告なしで https の直ストリームを公開している SomaFM(4チャンネル)と Radio Paradise(4ミックス)の計8局を HTML の中に直接書く。URL は 2026-10-03 に実際に音声(`audio/mpeg`)が返ってくることを確認した。一覧は [設計書 3. 局の一覧](../design/03-局の一覧.md) に記録する。
- **検討した代替案**: radiko・らじる★らじる(組み込みができないため不採用)。BBC(2025年7月から BBC Sounds が英国外をブロックしており、日本から安定して聴けないため不採用)。KEXP・FIP・Radio Swiss Jazz / Classic・NTS・Rinse FM・Intergalactic FM(候補として残し、URL を確かめてから追加を検討する)。最初から Radio Browser API で局を検索する案(第2版以降の候補とする)。
- **結果・影響**: 確実に流れる局から始められる。一方、ストリームURLは放送局の都合で変わることがあるため、流れなくなったら URL を確認し直す必要がある。再生できないときは画面にエラーを表示して気づけるようにする。
