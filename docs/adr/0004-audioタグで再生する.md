# ADR-004: 再生は audio タグにストリームURLをセットするだけにする

- **ステータス**: 採用
- **背景**: ブラウザで音声を流す方法には、HTML の `<audio>` タグと、集中トマトで使った Web Audio API がある。Web Audio API で外部の音声を加工(波形表示など)するには、放送局側が CORS という仕組みで許可している必要があり、局によって対応がまちまち。
- **決定**: `<audio>` タグを1つ置き、局のボタンが押されたら `src` にストリームURLをセットして `play()` する。音量は `audio.volume` で変える。停止するときは `pause()` するだけでなく `src` を外して受信を止める(そのままだと裏で受信を続けるため)。もう一度再生するときは URL をセットし直し、少し前の続きではなく今の放送から流す。
- **検討した代替案**: Web Audio API で再生する案(CORS の対応が局ごとに違い、流れない局が出るおそれがあるため不採用。波形表示などの演出をしたくなったら改めて検討する)。
- **結果・影響**: 仕組みが単純で、直ストリームを公開している局ならほぼどこでも流せる。ブラウザは操作なしの自動再生を止めるため、再生は必ずボタンを押したときに始める。iPhone・iPad の Safari では JavaScript から音量を変えられない(本体の音量ボタンで調整する。画面での扱いは [ADR-006](0006-音量を変えられない端末ではスライダーを止める.md))。
