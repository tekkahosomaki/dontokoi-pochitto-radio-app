# 1. 概要 — ポチッとラジオ

海外のネットラジオを、局のボタンをポチッと押すだけで聴けるブラウザアプリ。SomaFM・Radio Paradise・KEXP・FIP・Radio Swiss・NTS・Rinse FM・Intergalactic FM の24局を収録している。ブラウザで HTML ファイルを開くだけで動く。

| 項目 | 内容 |
|---|---|
| アプリ名 | ポチッとラジオ(画面上の表記は「どんと来い！ポチッとラジオ」(「！」は全角)。いったんローマ字の「Pochitto Radio」にしたが、日本語表示を見比べて変更した。表示部の初期表示は「POCHITTO RADIO」、タブのタイトルは「ポチッとラジオ」) |
| 製作 | どんと来い！ガジェットラボ(画面の一番下と HTML の `author` に表示) |
| リポジトリ | `tekkahosomaki/dontokoi-pochitto-radio-app` |
| 形式 | HTML ファイル1つ(CSS・JavaScript を内蔵) |
| 公開 | Claude のアーティファクト |
| 動作環境 | 一般的なブラウザ(Edge / Chrome / Safari など)。放送の受信にインターネット接続が必要 |
| ソース | `apps/pochitto-radio.html` |

技術選定の経緯は [docs/adr](../adr) を参照。

## 版ごとの範囲

- **第1版**: 24局のボタン、再生 / 停止、音量、今流れている局名の表示、再生できないときのエラー表示(詳しくは [2. 画面と操作](02-画面と操作.md))
- **第2版以降の候補**(順番は未定)
  - Radio Browser API で局を検索する
  - お気に入りの局をブラウザに保存する
  - SomaFM のビットレート(音質)を切り替える
  - 今流れている曲名を表示する(対応している局だけ)

## 動作確認のしかた

`apps/pochitto-radio.html` をダブルクリックしてブラウザで開き、局のボタンを押して音が出ることを確かめる。アーティファクトとして公開したときにも流れるかを、公開後に確認する。
