# 2. 画面と操作 — ポチッとラジオ(第1版)

## 画面の構成

上から順に次のものを並べる。

1. **タイトル**: 「どんと来い！ポチッとラジオ」(タブのタイトルは「ポチッとラジオ」)。右側に「STEREO NET TUNER」の飾り文字。スマホの幅では飾り文字をタイトルの下の行に回す
2. **今流れている局**: 局名と放送局(例:「Groove Salad — SomaFM」)、状態(停止中 / 接続中… / 再生中 / エラー)
3. **操作**: 再生 / 停止ボタン、音量スライダー
4. **局のボタン**: 放送局ごと([3. 局の一覧](03-局の一覧.md) の順)にまとめて並べ、CH01〜CH27 の番号を付ける。各ボタンには局名と、ジャンルの短い説明を表示する。再生中の局のボタンは色を変えて目立たせる
5. **フッター**: 製作者名「どんと来い！ガジェットラボ」

スマホの幅でも横にはみ出さないよう、局のボタンは画面の幅に合わせて折り返す。

## 公開ページで聴けない局

局によっては、公開先のドメインからのアクセスを断る([3. 局の一覧](03-局の一覧.md))。ページを開いたときのドメイン(`location.hostname`)がその局の「再生できない公開先」(`blockedOn`)と一致したら、その局のボタンを最初から押せない状態にする。

- ボタンの色を暗くし、ランプも消す。ジャンルの説明の代わりに「公開ページでは聴けません」と表示する
- その放送局の見出しの横に「ファイルをダウンロードして開くと聴けます」と橙色で添える。これはリンクで、押すと公開ページと同じ場所にある元の HTML が `pochitto-radio.html` としてダウンロードされる(ブラウザの「名前を付けて保存」だと、表示し終わった状態が保存されて元の HTML と中身が変わるため)
- ダブルクリックで開いたとき(`file://`)など、ほかのドメインでは今までどおり押せる

今のところ対象は SomaFM の8局で、GitHub Pages(`github.io`)で開いたときに押せなくなる。

## 「名前を付けて保存」したファイル

ブラウザの「名前を付けて保存」(Ctrl+S)で保存すると、作り終わった局のボタンやレベルメーターがファイルに書き込まれる。そのまま開くとボタンが二重に並び、保存されたほうのボタンは押しても動かない。これを防ぐため、ページを開いたときは局のボタンとレベルメーターをいったん空にしてから作り直す。保存したファイルでも、元の HTML と同じように動く。

## 操作

| 操作 | 動き |
|---|---|
| 局のボタンを押す | その局に切り替えて再生する(別の局が流れていたら、そちらは止まる) |
| 再生中の局のボタンをもう一度押す | 停止する |
| 再生 / 停止ボタン | 停止中なら最後に選んだ局を再生し、再生中なら停止する。まだ局を選んでいないときは押せない |
| 音量スライダー | 音量を変える(0〜100)。iPhone・iPad では押せない(下の「音量を変えられない端末」) |

- 停止したあとにもう一度再生すると、止めたところの続きではなく今の放送から流れる([ADR-004](../adr/0004-audioタグで再生する.md))。
- ページを開いただけでは音は出ない。ブラウザが操作なしの自動再生を止めるため、必ずボタンを押してから再生する。

## 状態の表示

| 状態 | 表示 |
|---|---|
| 停止中 | 局をまだ選んでいなければ「局を選んでください」、選んでいれば局名と「停止中」 |
| 接続中 | ボタンを押してから音が出るまでの間、「接続中…」 |
| 再生中 | 局名と「再生中」 |
| エラー | 「この局は今は再生できません」。ほかの局は選べるままにする |

## 見た目

1980〜90年代に日本ではやった、豪華なミニコンポ・ステレオ風にする。暗い色をベースにする。

- **本体**: 黒〜濃いガンメタルのパネル。ヘアライン(細い筋)の入った金属風の質感と、銀色の縁取り
- **表示部**: 黒い窓の中に、青緑に光る蛍光表示管(FL管)風の文字で局名・状態を表示する。再生中は、表示部の中でレベルメーター風の棒が動く(音に合わせて動くのではなく飾りの動き。[ADR-004](../adr/0004-audioタグで再生する.md) のとおり音声は加工しないため)
- **局のボタン**: 銀色のプッシュボタン風。再生中の局はボタンの上の小さなランプ(橙色)が点灯する
- **再生 / 停止ボタン・音量**: 再生 / 停止は大きめのボタン、音量はつまみ風の見た目のスライダー
- **文字**: 外部フォントは使わない([ADR-001](../adr/0001-HTMLファイル1つで動くブラウザアプリ.md))。表示部の文字は等幅フォントで蛍光表示管らしく見せる

## 音量の初期値

70(0〜100)。

## 音量を変えられない端末

iPhone・iPad では、どのブラウザでもページから音量を変えられない([ADR-006](../adr/0006-音量を変えられない端末ではスライダーを止める.md))。ページを開いたときに音量を変えられるかを試し、変えられない端末では次のようにする。

- 音量スライダーを押せない状態にし、薄く表示する
- 数値(70)の代わりに「音量は本体のボタンで調整」と表示する

音量は、端末本体の音量ボタンで調整してもらう。Android やパソコンでは今までどおりスライダーで変えられる。

## 保存するもの

第1版では何も保存しない。ページを開き直すと、停止中・音量70に戻る。(お気に入りの保存は第2版以降の候補)
