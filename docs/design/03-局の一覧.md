# 3. 局の一覧 — ポチッとラジオ(第1版)

第1版で収録する34局。最初の8局(SomaFM・Radio Paradise)のあとに、候補として挙がっていた15局、SomaFM のテクノ寄りの4チャンネル、テクノ専門の7局を追加した。最初の8局のURL はすべて 2026-10-03 に、実際に音声(`audio/mpeg`)が返ってくることを確認した。選んだ理由は [ADR-003](../adr/0003-https直ストリームを公開している局だけを使う.md) を参照。

## SomaFM(アメリカ・サンフランシスコ)

リスナーの寄付で運営される、広告なしのネット専業局。音質は MP3 128kbps を使う。

| 局名 | ジャンル | ストリームURL |
|---|---|---|
| Groove Salad | アンビエント / ダウンテンポ | `https://ice1.somafm.com/groovesalad-128-mp3` |
| Drone Zone | ビートのほぼない音響系 | `https://ice2.somafm.com/dronezone-128-mp3` |
| Deep Space One | スペース系の電子音楽 | `https://ice4.somafm.com/deepspaceone-128-mp3` |
| Beat Blender | ハウス / ダウンテンポ | `https://ice6.somafm.com/beatblender-128-mp3` |
| The Trip | プログレッシブハウス / トランス | `https://ice2.somafm.com/thetrip-128-mp3` |
| DEF CON Radio | 暗めでビートの強い電子音楽 | `https://ice4.somafm.com/defcon-128-mp3` |
| cliqhop idm | IDM(電子音とビート中心) | `https://ice6.somafm.com/cliqhop-128-mp3` |
| Dub Step Beyond | ダブステップ / 重低音系 | `https://ice1.somafm.com/dubstep-128-mp3` |

The Trip・DEF CON Radio・cliqhop idm・Dub Step Beyond の4チャンネルは、テクノ寄りの局がほしいという要望で 2026-10-03 に追加した(Radio Paradise にはテクノ系のチャンネルがなかったため)。音声が返ってくること、参照元が `github.io` だと断られること(403)、ダブルクリックで開いたファイルで4チャンネルとも鳴ることを同日に確認した。SomaFM のほかのチャンネルと同じく、公開ページではボタンを押せない。

## 低音質の配信

「低音質(データ節約)」を選んだときに使う配信([ADR-007](../adr/0007-低音質の配信に切り替えてデータ量を減らす.md))。HTML の局の一覧の `low` に書く。2026-10-03 に、URL から音声が返ってくることを確認した。SomaFM 以外は、公開ページの上で再生できることも確認した。

| 局 | 通常 | 低音質 | 低音質の URL |
|---|---|---|---|
| SomaFM(8局) | MP3 128kbps | AAC 64kbps | 通常の URL の `-128-mp3` を `-64-aac` にしたもの(例: `https://ice1.somafm.com/groovesalad-64-aac`) |
| Radio Paradise Main Mix | MP3 192kbps | AAC 64kbps | `https://stream.radioparadise.com/aac-64` |

| KEXP | AAC 160kbps | AAC 64kbps | `https://kexp.streamguys1.com/kexp64.aac` |
| FIP(本局のみ) | MP3 128kbps | AAC 96kbps | `https://icecast.radiofrance.fr/fip-midfi.aac` |

## メモ

- SomaFM は、接続元によって 403 ではじくことがある(2026-10-03 に確認)。
  - ブラウザ以外のツール(curl など)の User-Agent。確認するときはブラウザと同じ User-Agent を付ける
  - Claude デスクトップアプリの内蔵ブラウザ(User-Agent に「Claude」が入る)。内蔵ブラウザでは SomaFM は再生できないので、動作確認は Radio Paradise で行う
  - 一部の参照元(`http://localhost`、`github.io` など)。`127.0.0.1` やアーティファクトのドメイン(`claude.ai`、`claudeusercontent.com`)からは再生できる
- このため、HTML の局の一覧では SomaFM の全チャンネルに `blockedOn: 'github.io'` を付け、公開ページ(GitHub Pages)ではボタンを押せなくしている([2. 画面と操作](02-画面と操作.md) の「公開ページで聴けない局」)。2026-10-03 に公開ページで SomaFM が流れないことを確認した。
- 流れなくなった局は、各局の公式サイトか Radio Browser で最新の URL を調べて、この表と HTML の両方を直す。
